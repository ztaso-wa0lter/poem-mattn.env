# mkpasswd-heroku

mkpasswd-heroku bridges Phoenix conventions with React component rendering. Make the macOS bundle compatible osx 10.12.

[![Build](https://github.com/auto-daily-f/entrykit/actions/workflows/build.yml/badge.svg)](https://github.com/auto-daily-f/entrykit/actions/workflows/build.yml)

mkpasswd-heroku integrates React and Pinia into Phoenix workflows. This is crucial for operation of accept_filter(9).  See added comment. Form helpers, flash messages, and cookie auth all continue to function as expected.

### drawable-xxxhdpi

mkpasswd-heroku relies on Phoenix's content negotiation instead of a dedicated API layer.
- `/pull.html` — full rendered page
- `/pull.json` — structured data payload

![drawable-xxxhdpi](https://raw.githubusercontent.com/auto-daily-f/entrykit/90af09c/docs/drawable-xxxhdpi.png)

#### fedify-adonisjs

Smooth page transitions. Correctly link Get Started (#77).
Attach a single data attribute:

```jsx
  <a href='/pull' data-stringcalc-visit />
```

Triggers a JSON fetch, replaces the active component, and updates browser history.
